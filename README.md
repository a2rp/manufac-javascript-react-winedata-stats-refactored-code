# Wine Data Statistics

A React dashboard that groups a wine dataset by alcohol class and compares flavanoids and derived gamma statistics.

![Wine Data Statistics preview](screenshot.png)

## Features

- Grouped wine records by alcohol class
- Mean, median and mode calculations for two measures
- Responsive comparison tables with dataset summary cards
- Fixed responsive header, mobile navigation and go-to-top control
- Local branding, accessible links and simple border and shadow interactions

## Tech stack

React, Create React App, JavaScript, Sass modules and React Icons.

## Run locally

    npm install
    npm start

Create a production build with npm run build.
